# Empoo Mart POS

A lightweight, front-end point-of-sale prototype for a small mart. It includes sales workflows, product management, customer loyalty, and reporting dashboards to mirror the core surface of a modern POS.

## Features
- Sales screen with quick picks, barcode search, held tickets, discounts, and multi-payment buttons.
- Product catalog management with cost/price tracking and in-place editing.
- Profit insight cards showing potential profit and weighted margin.
- Customer/loyalty list with points tracking.
- Daily reporting overview and export stub.
- Store settings, hardware status, and shift controls.

## Run locally
```bash
python3 -m http.server 8080
```
Open <http://localhost:8080>.
